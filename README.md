# Modern Portfolio

A modern, responsive portfolio website built with **Next.js** to showcase projects, skills, and contact information.

## ✨ Features

- Clean, modern UI
- Fully responsive design (mobile, tablet, desktop)
- Fast performance with Next.js
- Easy-to-update project/content sections
- SEO-friendly structure
- Ready for deployment on Vercel
- Switch themes (light, dark, espresso, tennis)
- Animations with framer motion 

## 🛠 Tech Stack

- [Next.js](https://nextjs.org/)
- React
- TypeScript (if enabled)
- CSS Modules / Tailwind CSS (update based on your setup)
- Vercel (recommended deployment)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/leonajosephine/modern-portfolio.git
cd modern-portfolio
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### 3. Run the development server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```bash
modern-portfolio/
├── app/              # App Router pages/layouts
├── components/       # Reusable UI components
├── public/           # Static assets (images, icons, etc.)
├── styles/           # Global/component styles
└── README.md
```

> Adjust this structure if your folders differ.

## 🎨 Customization

You can personalize the portfolio by updating:

- **Hero/About section** (name, bio, role)
- **Projects section** (title, description, links, tech stack)
- **Skills section**
- **Contact links** (GitHub, LinkedIn, email, etc.)
- **Metadata** for SEO (`title`, `description`, Open Graph)

## 📦 Build for Production

```bash
npm run build
npm run start
```

## 🌐 Deployment

This project is easiest to deploy with [Vercel](https://vercel.com/new).

1. Push your code to GitHub
2. Import the repository into Vercel
3. Deploy
